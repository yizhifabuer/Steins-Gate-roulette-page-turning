# 命运石之门滚轮补丁 0.3.2

双击本文件夹中的 SteinsGateWheel.exe，或双击桌面上的“石之门滚轮补丁”快捷方式，然后正常打开游戏即可使用。

支持 Steam 版《命运石之门》原版和《命运石之门 0》。向下滚轮等同左键，支持连续滚动。

如需登录 Windows 自动运行，在本文件夹运行一次 SteinsGateWheelSetup.exe，点击“安装并启用”。从旧版升级时，也用这一步更新原来的自启路径。以后手动使用只需双击主程序。

双击“停止补丁.cmd”可临时停止。移动整个文件夹后，重新创建桌面快捷方式；已登记自启时，运行新位置的安装器更新路径。

分享给别人时直接上传本文件夹里的四个文件。每位用户可以右键 SteinsGateWheel.exe 创建自己的桌面快捷方式。

如果运行中突然失效，请提供本文件夹内生成的 SteinsGateWheel-error.log。TIPS 场景尚待游戏内验证。
